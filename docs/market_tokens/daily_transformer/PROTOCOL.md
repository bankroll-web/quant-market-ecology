# Frozen recipe: daily token transformer development experiment

2026-10-03. Existing 2023–2026 data have already been inspected in regression studies. All results here are exploratory chronological comparisons, not untouched project-level validation.

Use the verified ten-coin daily dataset and existing one-day processing-delay convention: feature day i available at open i+1, execute at open i+2, outcome open i+3. No training label may be available after its stage cutoff. Do not claim multi-year intraday book coverage.

Forty fields per completed daily frame: return, log quote volume, Parkinson variance and Amihud proxy for each of ten coins. Encode into sixteen train-quantile bins with explicit below/above-training-range categories. Fit tokenizer only to observations available at or before 2024-10-01 00:00 UTC. Original numeric outcomes remain separate. Use sixteen consecutive daily frames as context; field tokens are embedded and combined into one frame embedding, with learned positional embeddings and a causal attention mask. This is not a faithful Chronos/PatchTST replication.

Architecture: token embeddings8, hidden width64, two transformer blocks, four attention heads, feed-forward128, dropout0.1. Self-supervised next-frame pretraining predicts the forty next-day field categories, ten epochs, using only next-frame observations available by 2024-10-01. Fine-tune a nine-category future-BTC-return distribution head for thirty epochs. Outcome cuts and per-category means fitted only from supervised training outcomes available by 2024-10-01. AdamW learning rate0.001, weight decay0.01, batch64, gradient norm limit1. Three pretrained seeds91/92/93; one no-pretraining control seed91. No architecture/learning-rate/context/cost search after evaluation.

Validation: resolved price outcomes after 2024-10-01 and at/before 2024-12-31. Select the epoch with smallest validation multiclass log loss. Temperature from0.5/1/2/4 selected by validation log loss only. Test execution dates2025-01-01 through2026-08-30, target ends2026-08-31. No training update after those cutoffs. Ensemble averages probabilities of the three separately calibrated pretrained models. It is not a separate pretrained foundation model.

Comparisons: initial supervised training-class prior, logistic regression on one-hot last-frame state with C0.1, the no-pretraining transformer and pretrained ensemble. Logistic class calibration uses the same validation temperatures. Convert forecast probabilities to expected log return using training category means. Trading convention stays frozen: long above+25bps, cash below-25bps, otherwise retain state. Cost0.25% per executed side; fixed0.05/0.10% sensitivities. Final liquidation charged. Include hold-BTC/cash on equal execution dates. Do not select the most profitable model/cost afterwards and certify it.

Report training/validation/evaluation counts and clocks, class distribution, chosen epochs/calibration, per-seed scores, categorical log loss/Brier/expected-return MSE, net returns/drawdowns/turnover, range flags, pretraining loss traces, compute duration, actual parameter counts and data hashes. Overlapping contexts are not independent examples; daily return targets do not overlap. Primary objective is an implementation/mechanism comparison, not a profitability guarantee. No live deployment or orders.

Sources: Chronos https://www.amazon.science/publications/chronos-learning-the-language-of-time-series ; PatchTST https://arxiv.org/abs/2211.14730 ; PyTorch causal transformer implementation https://docs.pytorch.org/docs/2.14/generated/torch.nn.TransformerEncoder.html . Neural modeling still uses mathematics and needs evidence of generalization.
